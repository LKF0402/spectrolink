# server-ndir：NDIR 非分散红外仿真（SpectroLink L2 参考）

> 由总 SKILL 自动调度读取。物理内核 `ndir_physics.py` + spectrolink_core。**不内置仪器，k_s/k_r/L 默认演示占位，真实器件参数须用户提供。**

## 原理速览

NDIR 用**宽带红外源 + 窄带滤光片**，不扫谱、无激光：

- 信号通道（带内吸收）：I_s = I₀·exp(−k_s·L_s·x)
- 参考通道（带外无吸收）：I_r = I₀·exp(−k_r·L_r·x)
- **比值**：R = I_s/I_r = R₀·exp(−(k_s·L_s − k_r·L_r)·x) → **lnR 与 x 严格线性**，光源波动/温度漂移一阶抵消

**k_s/k_r 是"带内等效吸收系数"**：由光源谱 × 滤光片透过 × 探测器响应 × 气体吸收卷积而来，不是单条吸收线系数，必须标定。

## 工具路由

| 任务 | 工具 |
|---|---|
| 单浓度正演：双通道信号/比值/解析反演 | `t_ndir_forward` |
| 浓度扫描标定：x_min..x_max → R(x) 表 + lnR 线性拟合 | `t_ndir_calibrate` |
| 比值 → 浓度解析反演：x = −ln(R/R₀)/(k_s·L_s−k_r·L_r) | `t_ndir_invert` |
| 数值锚点自检（离线） | `t_ndir_selftest` |

## 关键参数（默认演示占位）

| 参数 | 默认 | 说明 |
|---|---|---|
| `x` | 5e-6 | 摩尔分数（1e-6=1ppm） |
| `k_s` | 0.05 | 信号通道带内有效吸收系数 [cm⁻¹] |
| `k_r` | 0.0 | 参考通道泄漏吸收系数 [cm⁻¹] |
| `L_s`/`L_r` | 依实现 | 两通道光程 [cm] |

## 物理坑点（必查）

1. **交叉干扰**：参考通道滤光片不可能完全排除目标气体吸收（k_r≠0），k_r 必须实测标定，否则高浓度端偏差。
2. **k_s 非单线系数**：带内等效系数随光源老化/温度漂移变化，标定周期决定精度。
3. **比值法适用域**：lnR−x 线性只在单指数吸收成立；H₂O 宽带吸收叠入信号带时需温湿度补偿。
4. **检测限受噪声下限约束**：`noise_frac` 演示 σ；低浓度端 R→R₀，误差由噪声主导而非线性度。
5. **数值锚点**：自检含 R₀ 与解析反演闭合断言。

## 交互契约

- `validation.overall`：`fail` 不得下结论；`warn`（默认演示占位）须披露。
- 标定结果用 `t_ndir_calibrate` 的 `A_fit`（=k_s·L_s−k_r·L_r）作为反演输入，勿手抄。
