# server-doas：DOAS 差分吸收光谱仿真（SpectroLink L2 参考）

> 由总 SKILL 自动调度读取。物理内核 `doas_physics.py` + spectrolink_core。**不内置仪器，默认截面/源为演示占位（NO₂ 448 nm 量级），真实截面须用户提供。**

## 原理速览

DOAS 在**紫外-可见宽带域**分离"慢变背景"与"分子窄带吸收"：

- 测量方程：ln(I₀(λ)/I(λ)) = P(λ) + σ(λ)·L·c
  - P(λ)：慢变背景（瑞利/米散射、光源包络、仪器透过）→ 低阶多项式拟合
  - σ(λ)·L·c：分子**差分吸收**（快变结构）
- 浓度反演：c = argmin ‖ln(I₀/I) − P(λ) − σ(λ)·L·c‖²（线性最小二乘）

**σ 单位 cm²/molecule**（非 cm⁻¹）；开放光路 L 为积分光程。

## 物理坑点（必查）

1. **单位制陷阱**：DOAS 用**波长 nm + σ cm²/molecule**，与 TDLAS/CRDS/FTIR 的**波数 cm⁻¹ + α cm⁻¹** 完全不同，跨技术对比必须先换算（λ[nm] ↔ ν[cm⁻¹] = 1e7/λ）。
2. **多项式阶数过拟合**：poly_deg 过高会吃掉分子窄带结构 → 浓度低估；选阶数看差分残差谱，非越低越好。
3. **截面谱必须实测/权威库**：σ(λ) 温压依赖强（O₄ 等），默认演示截面不可当真实值引用。
4. **宽带源包络不可比**：I₀ 与 I 必须同一次测量链路，否则 P(λ) 拟合不干净。
5. **数值锚点**：自检含差分反演闭合断言。

## 交互契约

- `validation.overall`：`fail` 不得下结论；`warn`（默认演示占位）须披露。
- 标定结果 `A_fit`（=σ·L）作反演输入，勿手抄。
