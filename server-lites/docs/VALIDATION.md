# 可信度与已知局限

本文件说明 lites-mcp 输出**哪些部分可信、可信到什么程度**，以及自动校验（`lites_review`）各判据的口径与使用边界。目的是避免两类误用：**把仿真值当实测值**、**把"提醒"当"结论被否"**。

> ⚠️ 本工具输出的是**理论仿真**，不是实验测量。论文中使用须按 README 的引用格式标注"理论仿真"。

---

## 1. 分层可信度

| 层面 | 可信度 | 判据 |
|------|--------|------|
| 取数层（HITRAN/HAPI） | **高** | 直接取自 HITRAN2024 线表，与独立实现相对偏差在 0.4% 量级 |
| 物理建模 · **标度律** | **高** | 对 $\eta_{abs}$、$P$、$H_{th}(f_m)$、$H_{mech}$、$Q$ 的函数形式与标度律正确；跨波段 $g$ 一致性可检验 |
| 物理建模 · **绝对量级** | **中** | **由一点实测锚定**（`_solve_gain`），不是第一性原理算出的绝对值 |
| 材料常数（$\Theta$ 比值 45.1×） | **高** | $\alpha_{te}$ / $d_{piezo}$ / $k_{th}$ 均为材料手册值，导出关系明确 |
| 涂层增益（2.920×） | **高** | 文献实测；QTF2→QTF3 在**几何与 Q 相同**条件下测得，增益**只能**归因于涂层 |
| **器件吸收率 $\eta_{dev}$** | ⚠️ **最大不确定度** | 波长的强函数（LiNbO₃ 声子吸收带 + 2.87 μm OH 基频，3.3 μm 在带肩），**未实机标定时所有定量结论应视为量级估计** |
| $f_0$ 温度系数 | **中** | 石英 ≈ −30 ppm/K、LiNbO₃ ≈ −80 ppm/K 为典型值，实机须标定 |
| $\tau_{acc}=Q/(\pi f_0)$ | **中** | 由文献"降 $f_0$ 增益能量积累时间"结论换算（约 19.7% 量级），**非独立实测** |
| $f_{cut}$（热扩散截止） | **中** | 依赖热扩散宽度 $w$ 与热扩散率 $D$；$w$ 未实机标定。这是"最优 2f < f0/2"结论的来源 |
| 1/f 噪声系数 | **低**（定性可靠） | 定性趋势可靠（kHz 段 1/f 主导），**绝对量级未逐器件标定** |
| 自检（`lites_selftest`） | **中** | 63 项全过（物理 35 + 仪器 28，2026-09-18 计入默认器件扩容），但多数为"自洽检验"（见 §2） || 保真度台账（`tools/lites_fidelity.py`） | 设计特性 | 把"效应 ↔ 实现位置 ↔ 是否真生效 ↔ 已知缺口"写成**可执行表**，并由源码证据与行为审计交叉核对。它保证**披露诚实**（不把未实现项说成已建模），**不提升物理精度** |

**结论**：标度律与相对比较可用于方法验证与系统选型；**绝对检测限不可替代实测**。

## 2. 自检（63 项）怎么看

`lites_physics.selftest()` 35 项 + `lites_tools.lites_selftest()` 28 项。**注意这两个数都是 "PASS + INFO 合计"**——部分项在 $\eta_{dev}$ 未实测时**按设计**只能给 INFO 而不能判 PASS/FAIL，这不等于失败。（2026-09-18 默认器件改为去壳商用音叉后，物理层由 29→35、仪器层由 24→28。）

| 组 | 内容 | 性质 |
|---|---|---|
| A. 标定自洽 | 9 个器件锚点回代，相对偏差 ≤ 2e-16 | **自洽**（模型与自身锚点一致） |
| B. 标度律 | $V(2P)/V(P)=2.000$；弱吸收 $\Delta V(2\alpha L)/\Delta V(\alpha L)=2.000$；吸收饱和（$\alpha L$ 0.1→0.2 仅增 1.90×）；$H_{mech}$ 峰在 $f_0$ | **独立互校** ✅ |
| C. 标定口径 | 三组器件族的 $g$/中位数跨幅（1.000× / 14.226× / 4841.285×） | **INFO**——$\eta_{dev}$ 未实测时**不可判 PASS/FAIL**（见 §4） |
| C2. 能量积累·涂层·材料 | $\tau_{acc}$ 律（预测 3.864× vs 实测 3.229×，偏差 **19.7%**）；涂层增益独立可分离（预测 2.920× vs 实测 2.920×，偏差 0.0%）；$\Theta$ = 45.1× | **独立互校** ✅（对照文献数值） |
| D. 共振跟踪 | 失谐 0.01% → −0.43 dB；温漂 1 K → −0.28 dB，3dB 带宽仅 6.468 Hz；$\tau_{acc}$ 与群延迟恒等式 | **自洽**（解析解对照） |
| E. 伪信号·MDL | 理想池 $V_{spur}=0$；伪信号浓度无关性；MDL 噪声线性 2.000 | **自洽** |
| 仪器口径 24 项 | 返回值结构、契约块完整性、单位一致性、边界行为 | 混合 |

**关键区分**：

- **B 组与 C2 组是真独立互校**——它们对照的是**外部文献数值或独立物理关系**，能证明物理建模方向正确
- **C 组按设计只能给 INFO**——这是**诚实**而非缺陷：$\eta_{dev}$ 未实机标定时，跨幅大小既不能证明对、也不能证明错
- **其余多为"自己验自己"**——能证明链路无代码 bug、无量纲错误，**不能证明物理建模与真实世界一致**

> **正确用法**：自检通过 = "实现自洽 + 标度律正确"；要判断**绝对精度**，须做外部交叉验证（§3）。

## 3. 外部交叉验证（推荐做法）

### 3.1 跨波段增益一致性（本项目最强判据）

对同一器件的多个波段，各自给出正确的 $P$ 与 $\eta_{abs}$，反解 $g$ 应当一致：

```
ln-mfp-c2h2：
  波段1  g = g₁
  波段2  g = g₂
  波段3  g = g₃
  max/min 应接近 1（在量测误差内）
```

若跨幅远超量测误差 → **锚点元数据（尤其 $\eta_{abs}$）写错了**，而不是"模型本来就这样"。

> 这条判据正是本项目改造的起因：初版把气体吸收系数当热源，导致同一器件三波段跨 80×，把真实物理伪装成了拟合常数。

### 3.2 涂层增益可分离性

QTF2 → QTF3，几何与 $Q$ 相同 → 测得的 2.920× 增益**只能**归因于涂层。对照 `thermoelastic_fom(mat, "pdms")["coating_gain"]`。

### 3.3 与文献检测限的量级比对

`lites_mdl(compare_literature=True)` 自动做此比对。已知锚点：

| 方法 | CH₄ 检测限 | 比值 |
|---|---|---|
| PAS（同器件 LN-MFP） | 49 ppb | — |
| **LITES（同器件）** | **22 ppm** | **450×** |

该 450× 与 $\eta_{dev}/(1-\eta_{dev})$ 的量级一致——**这本身就是 $\eta_{dev}$ 口径正确的旁证**。

### 3.4 α 的独立复算

对同一波数窗口，用独立脚本按 HITRAN 线表手算 $\alpha L$，与返回的 $\alpha$ 对比，相对偏差应在 0.4% 量级。

## 5. 交互契约层的边界（重要）

工具返回里带 `assumptions` / `next_required_actions` / `disclosure_pending` 三个
**机器可读**字段（MCP 层 `_wrap()` 保证它们一定存在），但：

| 服务器**能**保证 | 服务器**不能**保证 |
|---|---|
| 三个契约字段一定存在（MCP 层强制补全） | 模型最终措辞里**真的说了** |
| `disclosure_pending` 反映本次结果该披露的项 | 模型没有换一种说法绕过 |
| `next_required_actions` 给出本次该做的动作 | 模型照做了 |

### 5.2 两条经实测标定的口径

1. **缺参数不阻断结论**。默认工况下 `assumptions` 有几十项（含全部器件参数）。若把"未确认"当阻断，就没有任何一个结果可用了。缺参数走**披露**，阻断只留给"这个数本身不可用"。
2. **不隐藏数据**。曾考虑"结论受限时把定量字段置 `null`"——未采纳：首次调用（必然有默认参数）就拿不到任何数，且用户无法自行复核。改为**数据保留、结论受控**。

## 6. 已知系统偏差方向

| 偏差源 | 方向 | 量级 |
|---|---|---|
| $\eta_{dev}$ 未标定 | **双向**（取决于器件/波长，可能高估或低估） | 数倍至一个量级 |
| 1/f 噪声未逐器件标定 | 若实际 1/f 更强 → **MDL 偏乐观** | 未知 |
| 未建模前放 1/f | **MDL 偏乐观** | 痕量场景可能主导 |
| 未建模 Allan 漂移 | **长积分 MDL 偏乐观** | 随积分时间累积 |
| SDOF 机械模型 | 忽略高次模态 → 可能高估单模响应 | 未知 |
| 理想 TIA | 忽略有限 GBW → **高 $f_m$ 处偏乐观** | 与 $f_m$ 相关 |
| `constr` 取常数 0.5 | **双向** | 未知 |
| **去壳音叉 Q 的个体差异**（默认器件） | 取单一常压实测值 → 绝对灵敏度**双向**偏差 | **±30%**（随壳残余/朝向/气压/气流） |
| **去壳音叉小尺寸噪声惩罚未建模**（默认器件） | **SNR 偏高、MDL 偏低估** | 约 **3×**（文献实测 1σ 0.3 mV） |
| **降压回收 Q 未建模** | 若实际降压 → **偏保守** | 700→5 Torr 实测 SNR ~4× |
| **跨器件电压含私有 $g$** | 直接比 $V_{2f}$ **无物理意义** | 实测可差 **27×** 假象 |

> **给定量结论时的建议措辞**：给标度律与相对比较；绝对检测限标注"基于文献锚点的量级估计，$\eta_{dev}$ 与 1/f 系数未实机标定"。
>
> **用默认器件（去壳音叉）时额外加一句**：本结果未含叉齿小尺寸的噪声惩罚，SNR 可能偏乐观约 3×；要保守估计请把 `sigma_V` 放大 3× 重算。

## 7. 兜底原则

1. **量级 ≠ 精度**。本工具能可靠回答"哪种器件更好""哪个方向更优""大概差几倍"，**不能**回答"检测限是 22.3 ppm 还是 22.7 ppm"。
2. **未建模项必须披露**。`lites_guide` 的 `fidelity` 块是唯一真源，不要凭记忆列举。
3. **标定锚点决定绝对量级**。换了器件但没给锚点 → 结果只是"同型号典型值"量级的估计，**不是该器件的真值**。
4. **反演的 σ 必须在目标浓度上求**。噪声不随吸收信号等比缩放，跨浓度外推可差一个量级。
5. **`sweep` 优于套公式**。最优 $f_m$ 受"机械共振要 $f_0/2$"与"热扩散低通压 $f_m$"双向拉扯，净效果几乎不可能手算准；`lites_sweep(var="f_m")` 是唯一可靠手段。
