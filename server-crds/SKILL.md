# server-crds：CRDS 腔衰荡光谱仿真（SpectroLink L2 参考）

> 由总 SKILL 自动调度读取。物理内核 `crds_physics.py` + spectrolink_core（HITRAN）。**不内置仪器，L_m/R 默认演示占位，真实腔参数须用户提供。**

## 原理速览

CRDS 不测透射光强，而测**腔内光子寿命 τ**：

- 空腔衰荡时间：τ₀ = L / (c·(1−R))
- 有吸收时：α(ν) = 1/(c·τ(ν)) − (1−R)/L
- 浓度反演：x = α_measured / α_pure_pk（α_pure 为同温压纯组分 HITRAN 谱峰）

**核心优势**：τ 测量对镜面反射率/激光强度波动一阶不敏感（比值型测量），等效光程 = c·τ₀ 可达 km 级。

| 任务 | 工具 |

## 物理坑点（必查）

1. **动态范围**：τ 与吸收呈倒数的强非线性。密集强带（如 CH4 2968 cm⁻¹，α_pure≈13 cm⁻¹）下 50 ppm 单程 αL≈0.065，对 R=0.999 腔 τ 缩短 >98%。**选线/定浓度时把 αL/(1−R) ≲ 0.1 量级**，否则 τ 短到无法测（需 GHz 采样）。
2. **R 是等效值**：含镜面散射、镀膜吸收、衍射损耗，不能只按 datasheet 反射率。
3. **ring-down 拟合**：对数线性拟合（ln I vs t），只取信噪比有效段；`fit_noise` 演示噪声对 τ 估计的影响。
4. **反演依赖 α_pure_pk**：HITRAN 谱峰须与实测同温压口径；同位素 `all` 时峰高含邻近同位素线贡献。
5. **横轴波数 cm⁻¹**（非 nm）；`tau0_empty` 是空腔基准，报告 τ 缩短比例比绝对 τ 更直观。
6. **数值锚点**：τ₀(1m, R=0.999) = 3.335641 μs；自检含此锚点断言。

## 交互契约

- `validation.overall`：`fail` 不得下结论；`warn`（默认，因演示占位参数）须在回答披露"默认参数为演示占位"。
